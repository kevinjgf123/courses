## 2. 颜色系统（纯硕磐橙红体系，≤4 hex）

| 角色 | hex | 用途 | 面积占比 |
| :--- | :--- | :--- | :--- |
| **主色 橙红** | `#FA4F24` | 标题强调、主色块、结构图主框架、页码强调 | ≤ 60% |
| **辅色 暖橙** | `#F87D2F` | 卡片头、图表第二系列、分层色阶次级 | ≤ 30% |
| **中性 墨黑** | `#0F1423` | 正文、标题（文字主色） | 剩余 |
| **底 纯白** | `#FFFFFF` | 内页背景 | ≥ 50% |

**中性灰（辅助，不计入 4 hex 上限）**：`#E8E8E8` 分割线 / `#8A8F99` 脚注 / `#F7F7F8` 浅底块。

**色彩面积分配（逐页见 §6）**：

| 角色 | 面积占比 | 说明 |
| :--- | :--- | :--- |
| 主色橙红 | ≤ 60% | 章节扉页整页铺、封面几何带、标题强调 |
| 辅色暖橙 | ≤ 30% | 分层色阶第二档、卡片头部 |
| 强调橙红 | ≤ 10% | 巨型数字、关键标注、焦点元素（Hero 页可到 15–20%） |
| 中性 | 剩余 | 文字、分割线、页脚 |

**色彩节奏规则**：
- **Hero 页**（01/03/09/16/25/26）：橙红 + 暖橙占比可提升至 15–20%。
- **Supporting 页**：橙红 ≤ 5%（仅标题强调 + 关键标注），白底主导。
- 至少 2 页色彩比例与其他页显著不同 → 章节扉页（满铺）与内容页（白底）天然差异 ≥ 10% ✔

### 2.1 渐变与半透明（本项目方案）

- **允许渐变**（仅限 3 处）：封面左侧几何带 `linear-gradient(160deg, #FA4F24 0%, #F87D2F 100%)`；章节扉页底 `linear-gradient(135deg, #0F1423 0%, #2A1810 100%)`；Hero 页巨型数字 `linear-gradient(135deg, #FA4F24 0%, #F87D2F 100%)` 文字渐变。
- **半透明**：章节扉页巨字编号 `rgba(255,255,255,0.08)`；橙红浅底块 `rgba(250,79,36,0.06)` / `rgba(250,79,36,0.12)`。
- **阴影**：卡片 `0 4px 16px rgba(15,20,35,0.06)`。
- **禁忌**：同一页 ≥2 套主色板；高饱和撞色铺满 ≥1/3；全篇每页配色比例雷同。

## 5. 配图系统

本项目以**结构化图示为主体**（咨询方法论天然是结构图），配图分三级：

| 等级 | 用途 | 规则 |
| :--- | :--- | :--- |
| **L1 主视觉** | 承担页面主要叙事：4A 分层架构图、战略金字塔、双向对齐矩阵、信息架构四组件、能力地图、技术演进路线图 | 占 B 区 ≥ 40%；用 **SVG 形状骨架 + 独立可编辑文本层** |
| **L2 支撑图** | 强化段落：步骤条、热力图、CRUD 矩阵、集成关系图 | ≥ 280×180；同样文图分离 |
| **L3 母版徽标** | 全篇统一角标：硕磐橙红小方块标识 | ≤ 64×64，全篇位置一致（C 区左侧）|

**本项目核心规则 —— 文图分离（强约束）**：
所有结构图的**形状层**（矩形/圆角矩形/chevron/箭头/分层色块/连接线）用内联 `<SVG>` 绘制；但**所有文字（节点标题、说明、数据、标签）必须是独立的 `<Text>` 可编辑元素，禁止烤进 SVG**。即「SVG 形状骨架」+「真实文本层」叠加。

**配图类型统一**：全篇仅用 **结构化图示（SVG + 文本层）**，**不使用摄影/插画/3D 生成图** —— 咨询方法论题材下，结构图的信息承载效率远高于生成图，且能保证图文一致、可编辑。此为本项目显式声明。

**Icon**：仅用 `FAIcon` 线性单色，橙红或墨黑，尺寸 24–48px；禁 emoji、禁彩色填充、禁渐变。
